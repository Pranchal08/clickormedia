# clickormedia
ClickOrMedia is an ultra-luxury, Awwwards-inspired digital agency platform built into a single file. It features a real-time WebGL 3D showroom (laptops, phones, crystal starfields), 360° touch/gyroscope physics, kinetic typography, and card-free holographic UI for digital marketing &amp; web engineering. Tech: HTML5, CSS3, JS, Three.js, GSAP.
